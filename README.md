# Список элементов

Два окна: доступные и выбранные. Состояние выбора и порядка хранится в памяти сервера.

## Запуск

```bash
npm install
npm run dev
```

Клиент: http://localhost:5173  
API: http://localhost:3001

## Продакшен

```bash
npm install
npm run build
npm start
```

Приложение будет на порту `3001` или `PORT`.
